# Vision

## Mission

สร้าง AI coding assistant ที่ทรงพลังและยืดหยุ่นสำหรับ developers ที่ใช้งานใน terminal โดยไม่ต้องออกจาก workflow

## Vision

### Core Principles

1. **Terminal-First Experience**
   - Developers อยู่ใน terminal ส่วนใหญ่ของเวลา
   - AI assistant ควรอยู่ใน terminal เช่นกัน
   - ไม่ต้องสลับ context ระหว่าง tools

2. **Clean Architecture**
   - Code ที่ maintainable และ testable
   - Separation of concerns ชัดเจน
   - Functional programming principles

3. **Extensibility**
   - Plugin system สำหรับ custom functionality
   - Multi-provider AI support
   - Open APIs สำหรับ integration

4. **Performance**
   - Fast responses ด้วย async/await
   - Efficient resource usage
   - Offline mode ด้วย cache

5. **Privacy**
   - Local-first data storage
   - No telemetry โดย default
   - User-controlled data sharing

## Goals

### Short-term (2026)

- ✅ Build stable TUI interface
- ✅ Implement core features (sessions, AI, Git, files)
- ✅ Support major AI providers
- ✅ Establish Clean Architecture foundation

### Medium-term (2026-2027)

- 🔄 Enhanced LSP integration
- 🔄 Plugin system with WASM
- 🔄 Collaboration features
- 🔄 Performance optimization

### Long-term (2027+)

- 📋 Multi-agent conversations
- 📋 Custom agent creation
- 📋 Platform support (Windows, macOS, Linux packages)
- 📋 Enterprise features (SSO, RBAC)

## Impact

### For Individual Developers

- เพิ่ม productivity ด้วย AI assistance ใน terminal
- ลด context switching ระหว่าง tools
- ทำงานได้เร็วขึ้นด้วย keyboard shortcuts
- Customizable ด้วย plugins และ skills

### For Teams

- Collaboration features สำหรับ team work
- Shared sessions และ workspaces
- Consistent workflows ด้วย configuration
- Integration กับ existing tools

### For Community

- Open source สำหรับ contribution
- Extensible plugin ecosystem
- Documentation และ examples
- Active development และ support
